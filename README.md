# Inno Sport Bot

Telegram-бот и Mini App для расписания, разовой и автоматической записи на спортивные занятия. Приложение администратора для Android, локальный Windows-монитор и серверная часть находятся в одном репозитории.

## Запуск на сервере

Для домашнего NAS с Ubuntu Server: [инструкция Ubuntu](deploy/ubuntu/README.md), установка Docker и запуск одной командой после настройки .env.

Инструкция Docker/Linux/NAS и перенос существующих пользователей: [DEPLOY.md](DEPLOY.md). Конфигурация Docker подготовлена; сборка контейнера на исходном ноутбуке не проверена из-за отсутствия Docker.

В репозитории нет рабочих данных. Токен, SQLite-базы, ключ шифрования, закреплённый ID владельца и ключ подписи APK переносятся отдельно. Не создавать новый secret.key вместо потерянного при восстановлении существующих пользователей.

## Windows

Python 3.11+:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
Copy-Item .env.example .env
# Заполнить BOT_TOKEN, MINIAPP_URL и параметры WEB_*.
.\.venv\Scripts\python.exe setup_owner.py YOUR_NUMERIC_TELEGRAM_ID
.\.venv\Scripts\python.exe bot.py
```

Не запускать второй экземпляр с тем же токеном. Скрипты start-app.ps1 и install-autostart.ps1 предназначены для Windows и требуют отдельно установленного cloudflared в .tools. Для сервера они не нужны.

## Возможности

- Расписание текущей и следующей недели, личный календарь, ручная запись и отмена.
- Цели автозаписи, очередь ожидания, напоминания за сутки и час.
- Синхронизация с порталом: изменения расписания и записей, учёт отмен на сайте без повторной записи до явного запроса пользователя.
- Авторизация университетской почтой; пароли и cookies шифруются Fernet.
- SQLite: подтверждённые и отменённые записи, журнал запросов с сокрытием ввода авторизации.
- Модерация через Android APK с одноразовым кодом Telegram, короткими сессиями и отзывом доступа.
- Просмотр двух баз владельцем, управление функциями, пользователями и установками Mini App.
- Уведомления владельцу об устойчивых сбоях портала и восстановлении; одиночные сбои остаются в журнале.
- Локальные ежедневные и ручные резервные копии с проверкой целостности.
- Отдельная панель Windows с показателями процесса и безопасной лентой команд.

Административная веб-страница отключена. При отсутствии закреплённого числового ID владельца доступ к модерации закрыт. Названия устройств/платформы — сведения клиента, не аппаратная идентификация; полный запрет доступа выполняется блокировкой Telegram ID.

## Код

- bot.py — Telegram-интерфейс и запуск.
- core.py, booking_features.py — хранение, клиент портала и координация записи.
- miniapp.py, web/ — API и интерфейс Mini App.
- moderation.py, moderator_auth.py, user_access.py — модерация и права доступа.
- server_operations.py — состояние и резервные копии.
- android/ — исходники Android, инструкция сборки и настройки подписи.
- monitor.py, monitor_desktop.py, monitor-web/ — локальная панель; [MONITOR.md](MONITOR.md).
- icon-pack/ — SVG-иконки и сборка.

Готовые EXE/APK и инструменты сборки не включены. Для монитора дополнительно установить requirements-monitor.txt; Android SDK/JDK и приватный ключ подписи APK настраиваются отдельно. Существующий ключ подписи нельзя публиковать или заменять при выпуске обновления установленного APK.

## Проверка

```sh
python -m unittest discover -p 'test_*.py' -q
node test_weekly_plan.cjs
node test_schedule_ui.cjs
```

Тесты используют имитацию Telegram и спортивного портала. Прохождение тестов не подтверждает живую авторизацию или доступность внешнего API на новом сервере. Настройки, лимиты и правила портала нужно учитывать при эксплуатации.

Попытки записи у открытия выполняются последовательно с паузой 1 секунду после ответа, без параллельного спама на одно занятие. При HTTP 429 сохраняется дополнительная пауза 15 секунд; обычная проверка расписания остаётся раз в 3 минуты.

Отдельный экспериментальный пользовательский APK, его тестовые команды и вход в эту версию не включены. Mini App продолжает открываться через /app. Исходники ранее существовавшего приложения модерации сохранены.
