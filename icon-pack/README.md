# Иконки Inno Sport

31 векторная пиктограмма: 30 спортивных направлений и запасная `sport` для неизвестного названия. Все 36 названий из `catalogue.json` сопоставлены в `manifest.json`. Уровни одного спорта используют общую иконку.

Иконки уже подключены к карточкам расписания, записей и автозаписи. Цвет берётся из CSS (`currentColor`), размер — 29 px на большом экране и 25 px на телефоне. Декоративные SVG скрыты от скринридера: название занятия находится рядом.

- `svg/` — отдельные SVG для повторного использования.
- `preview.html` — галерея, которую можно открыть локально в браузере.
- `preview.png` — снимок галереи.
- `build.py` — исходные контуры, правила выбора по названию и сборка.

После изменения контуров или правил выполните из папки проекта:

```powershell
.\.venv\Scripts\python.exe .\icon-pack\build.py
```

Сборка обновляет SVG, manifest, галерею и блок иконок в `web/app.js`. Сервер читает статические файлы при запросе, поэтому перезапуск бота не нужен. Закройте и заново откройте Mini App, чтобы загрузить обновление. В разметку SVG попадают только постоянные контуры из сборки; названия занятий не вставляются в HTML.
