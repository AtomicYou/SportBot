# Debian 13 на домашнем сервере

Целевая система: Debian 13 (trixie), amd64 или arm64. На QNAP TS-451A с Intel — amd64.
Графический рабочий стол не требуется. Бот запускается через Docker Compose и автоматически
возвращается после перезагрузки благодаря Docker systemd service и restart: unless-stopped.

## Установка

На сервере по SSH:

```bash
sudo apt-get update
sudo apt-get install -y git python3
git clone https://github.com/AtomicYou/SportBot.git
cd SportBot
sudo bash deploy/debian/install-docker.sh
cp .env.example .env
chmod 600 .env
nano .env
```

Указать BOT_TOKEN, постоянный внешний HTTPS-адрес MINIAPP_URL и SPORTBOT_DATA_DIR.
По умолчанию данные находятся в ./data. Для другого локального диска подходит отдельный
каталог, например /srv/sportbot-data. Рабочие SQLite-базы размещать на локальной файловой
системе сервера; готовые резервные копии можно переносить на другой носитель.

Установщик использует официальный репозиторий Docker для Debian, suite trixie:
[инструкция Docker](https://docs.docker.com/engine/install/debian/).
Существующую установку Docker с Compose сохраняет. При конфликтующих пакетах или отсутствии
Compose останавливается, чтобы не менять действующую контейнерную среду без разбора.

## Перенос и запуск

Если сохраняются пользователи с ноутбука, перед запуском выполнить перенос по
[DEPLOY.md](../../DEPLOY.md): остановить старый бот, передать согласованные копии обеих баз,
исходный secret.key, moderator-identity.json и .env приватным каналом.
Не запускать ноутбук и сервер одновременно с одним токеном.

Каталог данных должен принадлежать UID/GID 10001. Проверить путь перед изменением прав;
не применять рекурсивный chown ко всему NAS. Установщик сам создаёт новый отсутствующий
каталог с нужным владельцем, но не меняет права существующего хранилища.

```bash
sudo bash deploy/debian/start.sh YOUR_NUMERIC_TELEGRAM_ID
sudo docker compose ps
sudo docker compose logs -f --tail=100 bot
```

Заменить YOUR_NUMERIC_TELEGRAM_ID своим числовым Telegram ID. Ранее закреплённый владелец
не заменяется. Порт 8082 доступен только на 127.0.0.1 сервера: направить на него HTTPS-прокси
или туннель, адрес которого указан в MINIAPP_URL. Получить свежие кнопки через /app и
код модерации через /moderation после переноса.

Контейнер использует собственный Python 3.12 и Debian bookworm внутри образа. Это отдельно
от Debian 13 хоста: системный Python сервера и его пакеты для бота не изменяются.
Отдельный экспериментальный пользовательский APK в эту поставку не входит.

Синтаксис скриптов проверен локально. Полная сборка контейнера, вход на портал и проверка
после перезагрузки Debian 13 ещё должны быть выполнены на самом сервере; Docker на исходном
Windows-ноутбуке отсутствует.
